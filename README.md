# Neon Dash

Neon Dash is an original, dependency-free rhythm platformer for the browser. It is inspired by the one-button obstacle-platforming genre, but uses original code, graphics, audio, and level design.

## Features

- Keyboard, mouse, and touch controls
- Responsive HTML Canvas rendering
- Original procedural Web Audio soundtrack and effects
- Normal and practice modes
- Automatic practice checkpoints
- Persistent best score and attempt counter
- Fullscreen and mute controls
- No external libraries or assets

## Controls

- **Space**, **W**, **Arrow Up**, click, or tap: jump / activate a nearby orb
- **P** or **Escape**: pause
- **R**: restart

## Run locally

Because the project is fully static, open `index.html` directly or serve the folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

The included Pages workflow deploys the repository root whenever `main` is updated. In the repository settings, open **Pages** and choose **GitHub Actions** as the source if it is not already selected.
